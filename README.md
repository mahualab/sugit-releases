# SuGit Releases

本仓库仅用于发布 SuGit 安装包、版本说明与 SHA-256 校验文件，不包含应用源码或源码历史。

## 下载

前往 [最新版本](https://github.com/mahualab/sugit-releases/releases/latest) 下载；目前提供 macOS 12 及以上 Apple Silicon（arm64）版本。每个版本的签名、公证和验证情况以该版本的发布说明为准。

## 更新源迁移

源码仓库 `mahualab/sugit` 改为私有，安装包改在本公开仓库发布。

迁移的 1.0.5 安装包与原发布完全一致，仍使用旧更新地址。源码私有后，该版本无法在应用内检查更新。请关注本仓库，待包含新更新地址的版本发布后，手动下载安装一次；迁移历史安装包本身不会改变已安装客户端的更新地址。

## 安装与校验

下载 DMG 后打开其中的 PKG，或直接下载 PKG。升级前请等待任务完成并退出 SuGit，再运行安装程序。

同一版本的安装包旁提供 `SHA256SUMS`，可在下载目录执行 `shasum -a 256 -c SHA256SUMS` 校验。
